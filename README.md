# EduReconstruye - Fase 2: Algoritmos de Búsqueda

Implementación y análisis de complejidad de los algoritmos de búsqueda **BFS**, **DFS** y **A*** sobre un grafo experimental, como parte del Proyecto Integrador de Inteligencia Artificial.

## 📋 Descripción

Este repositorio contiene el código fuente en Python que implementa tres estrategias de búsqueda para encontrar una ruta de intervención de menor costo operativo estimado en un grafo que abstrae la recuperación educativa en el Chocó.

- **BFS (Breadth-First Search)**: Búsqueda no informada que minimiza el número de aristas.
- **DFS (Depth-First Search)**: Búsqueda no informada que explora en profundidad.
- **A***: Búsqueda informada que utiliza una heurística de distancia euclidiana (admisible y consistente) para minimizar el costo del camino.

## 🛠️ Tecnologías y Requisitos

- **Python 3.8 o superior**.
- El código utiliza únicamente la **biblioteca estándar** de Python (`collections`, `heapq`, `math`, `time`, `statistics`). No se requieren dependencias externas.
